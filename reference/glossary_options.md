# Set/get global glossary options

Global glossary options are used, for example, to set the default path
for the glossary file.

## Usage

``` r
glossary_options(...)
```

## Arguments

- ...:

  One of three: (1) nothing, then returns all options as a list; (2) a
  name of an option element, then returns its value; (3) a name-value
  pair which sets the corresponding option to the new value (and returns
  nothing)

## Value

a list of options, values of an option, or nothing
