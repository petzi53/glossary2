# Package index

## Main Functions

Core functions for adding glossaries to documents

- [`glossary()`](https://www.peter-baumgartner.net/glossary2/reference/glossary.md)
  : Display glossary entry
- [`glossary_add()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_add.md)
  : Add a definition
- [`glossary_table()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_table.md)
  : Display glossary table
- [`glossary_load_all()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_load_all.md)
  : Load all definitions

## Styling & Configuration

Control appearance and behavior of glossary terms

- [`glossary_style()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_style.md)
  : Create CSS styles for glossary entries
- [`glossary_options()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_options.md)
  : Set/get global glossary options
- [`glossary_reset()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_reset.md)
  : Reset glossary table
- [`glossary_popup()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_popup.md)
  : Set or get the default popup type
- [`glossary_persistent()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_persistent.md)
  : Set or get the path to a persistent table object
- [`glossary_path()`](https://www.peter-baumgartner.net/glossary2/reference/glossary_path.md)
  : Set or get the default glossary path

## Quarto Integration

Set up persistent glossaries in Quarto documents

- [`add_to_quarto()`](https://www.peter-baumgartner.net/glossary2/reference/add_to_quarto.md)
  : Add glossary helper files to a quarto book
